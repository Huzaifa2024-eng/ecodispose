The problem

Electronic waste needs a better route.

Discarded electronics can contain hazardous materials as well as valuable recoverable resources. They should not be mixed with ordinary household waste.

🧪

Protect the environment

Improper handling can release harmful substances into soil and water. Use appropriate collection and recycling channels.

🔩

Recover useful materials

Responsible recycling can recover materials and components, reducing the need for some newly extracted resources.

📍

Make disposal simpler

A clear request and collection workflow helps people identify the next step instead of leaving old devices unused or discarding them incorrectly.

System workflow

Input → Processing → Output

The core logic behind the proposed digital solution.

01 / INPUT

Capture details

Device category, quantity, condition, area, and preferred disposal method.

02 / PROCESS

Validate & classify

Check required fields, categorize the item, and create a unique request ID.

03 / MATCH

Choose a route

Present suitable disposal options for the user to verify and select.

04 / OUTPUT

Track & summarize

Display request status, item totals, and a downloadable CSV summary.
